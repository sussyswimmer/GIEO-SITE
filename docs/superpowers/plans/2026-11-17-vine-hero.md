# Vine Hero Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Open the home page on GIEO with a 3D vine around it; scrolling grows a tree that drops the seed the existing film then plants.

**Architecture:** Act 1 is a new prefix of the hero pin: a second R3F canvas inside `[data-hero-ground]`, above the film and below the word, paints the film's own backdrop plus a procedural vine/tree/seed. At the handoff it fades away over the film's frame 0. Act 2 is the existing timeline, remapped into the rest of the run.

**Tech Stack:** Next.js 15, React 19, @react-three/fiber 9, three 0.187, GSAP ScrollTrigger (motion-runtime.ts), node:test.

**Spec:** docs/superpowers/specs/2026-11-17-vine-hero-design.md

## Global Constraints
- Full tier only for Act 1; Lite/Still/reduced motion/no JS keep today's hero.
- No new copy keys; copy only from src/content/*.json.
- Colours only from tokens (--stem-mint, --petal-soft, --lotus-pink, --cream, --plum-ink).
- The headline stays live HTML text and the LCP element; nothing 3D above it.
- Scroll is never blocked.

## Review Focus
1. Reload mid-hero: Act 1 must jump to the scroll position, not replay from 0 (first-frame jump, as in ShowroomScene).
2. Resize/rotate mid-hero: the seed's landing point must follow the film's cover fit (recomputed per frame from the stage box).
3. Lite tier: no data-vine, hero run as today (CSS gated on html[data-vine]).
4. Handoff: no frame where both seeds or neither seed shows (crossfade overlap pinned by a vine.ts test).
5. Short phones (390×844, portrait set): canopy stays under the nav and inside the screen.
